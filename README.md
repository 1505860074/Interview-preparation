## 目录结构

```
面试准备/
├── 工作内容分类汇总.md          # ★ 本份工作全部内容按技术栈/工作类型分类沉淀（四套本地知识库交叉检索）
├── 简历/                       # 简历（HTML）
│   ├── 姚金盟-简历-CodingAgent.html   # 当前最新版（版本靠 git 维护，文件名不再带 v 后缀）
│   └── 历史版本/               # v9 / v9-两页 / v10 / v11 / v12
├── 面试刷题/                   # 面试刷题准备清单
│   ├── Coding Agent岗位面试刷题准备清单-v3.md   # 当前最新版
│   └── 历史版本/               # 清单.md / v2
├── 学习资料/                   # 学习路线 / 知识手册 / 面试专项 / 优化建议
│   ├── Python与Bash面试专项-v1.md      # Python + Bash 面试自学全书（结合项目，当前最新）
│   ├── Bash面试知识手册.md              # Bash 自学 + 面试手册（含题库）

```

## 说明

- **简历 / 面试刷题**：外层只保留当前最新版本，历史迭代版本统一归档在各自的 `历史版本/` 子目录中。
- **项目准备**：暂为空目录，用于后续补充项目相关的准备材料。
- 本仓库使用 git 进行版本管理。
