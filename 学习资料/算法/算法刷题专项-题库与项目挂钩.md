## P7 动态规划（打底）

| 题 | Δ | 一句话思路 |
|---|---|---|
| 爬楼梯 | E | `dp[i]=dp[i-1]+dp[i-2]`，O(1) 空间 |
| 最大子数组和 | E | Kadane（同 P2） |
| 买卖股票（可交易一次） | E | 记录 `min_price` 和 `max_profit` |
| 硬币找零（完全背包） | M | `dp[j]=min(dp[j],dp[j-w]+1)`，一维从大到小 |
| 0/1 背包 | M | `dp[j]=max(dp[j],dp[j-w]+v)`，一维**从小到大** |
| 编辑距离 | M | 三操作 min(删/插/换) | ★★模糊检索/相似度可挂 |
| 最长公共子序列 | M | 双序列 DP | ★两文本查重/一致性比对 |

**注意递归写法会 TLE（指数），做题前先想：这题 O(n) 一维 DP 就能解。**

## P9 弱覆盖区自查（有余力再刷）

- **位运算底层**：异或基础（`^`）、`n & (n-1)` 清最后 1 位、判断 2 的幂。
- **前缀和**（数组任意区间和 O(1)）。
- **并查集**（判连通/分组，Kruskal 前置，**低频若考多为模板题**）。
- **单调栈**（下一个更大元素）——Medium 偶尔出。
- **回溯/组合枚举**（子集、全排列）——面试更常考"递归回溯模板"：
```python
def dfs(path, choices):
    if not choices: record(path); return
    for i, c in enumerate(choices):
        dfs(path+[c], choices[:i]+choices[i+1:])
```
> 优先级别：并查集/单调栈/回溯**只需要知道模板存在**，笔试很少单独考难版。**别为这三类拖节奏，先保证 P0–P6 能全对。**

## P10 考前自测清单（10 题卡点测，10–15 分钟/题）

1. 最长无重复字符子串 ★（滑窗）
2. 版本号比较 ★★（拆段+pre）
3. 三数之和 ★（哈希+双指针）
4. 前序+中序还原二叉树
5. 岛屿数量 ★（网格 DFS）
6. 课程表（拓扑判环）
7. 反转链表（三指针）
8. LRU Cache ★★（手写全）
9. 爬楼梯 + 编辑距离（DP 骨架）
10. 最小栈（数据+最小双栈）

> **自测通过标准**：不看资料手写全对 + 每题能口述模板选择理由 + 第 3/8/2 题能挂到你的项目（滑窗窗↔上下文、LRU↔KV Cache、版本号↔pre）。

> **本册一句话**：优先把 **P0 两类（字符串/滑窗、设计题 LRU）+ 树/图模板**刷透——这三块既覆盖笔试高频，又能直接挂到你的 Agent/CRG/版本管理项目上。**高考频样的取舍**：DP 每个会一道骨架、贪心/并查集知道模板就行，别陷进题海。
