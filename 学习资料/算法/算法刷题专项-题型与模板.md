## Part 1 哈希表（最基础，出现率最高）

**适用**：找"是否存在/配对/计数/去重"，或需要 O(1) 判断元素是否见过。
```python
from collections import Counter, defaultdict

# ① 计数
cnt = Counter(arr)
# ② 存在性（配对/去重用 set）
seen = set()
# ③ 原地建映射：值 -> 下标
pos = {v: i for i, v in enumerate(arr)}
# ④ 按 key 分组
groups = defaultdict(list)
for k, v in pairs: groups[k].append(v)
```
**关键点**：用哈希把"遍历找配对"从 O(n²) 降到 O(n)；判断"有无重复"用 `len(set)!=len(arr)`。

**题**：两数之和 / 字符串中第一个不重复字符 / 字母异位词分组 / 存在重复元素。

## Part 2 双指针 / 对撞指针 / 快慢指针

**适用**：有序数组、或问题有"两端往中间"的单调性。
```python
# 对撞（有序两数之和）
l, r = 0, len(nums)-1
while l < r:
    s = nums[l] + nums[r]
    if s == target: return [l, r]
    elif s < target: l += 1
    else: r -= 1

# 快慢指针（找中点/判环）
slow = fast = head
while fast and fast.next:
    slow = slow.next; fast = fast.next.next
```
**关键点**：对撞指针依赖**单调性**（和太大就右指针左移）；快慢指针找中点/环/交点都是 O(n)/O(1)。

**题**：三数之和（排序+固定一个+对撞）/ 有序数组移除重复 / 环形链表 / 盛最多水的容器。

## Part 3 滑动窗口（★Agent 岗高频）

**适用**：**连续子串/子数组**、求"最长的满足条件的"、或"刚好满足条件的最短"。
```python
# 定长窗口
for i in range(n):
    win.append(arr[i])
    if len(win) == k: ...   # 处理
# 变长窗口（最常考）：满足条件就收缩，不满足就扩张
left = 0
for right in range(n):
    ...更新窗口状态(加 arr[right])...
    while 窗口满足条件:
        记录答案(用 right-left+1)
        移除 arr[left]; left += 1
```
**关键点**：维护窗口状态（计数/和），右指针扩张、左指针收缩，**目标是"不重复/最长满足"就右扩左缩**。题目信号词："**子串/连续/最长/最短/不重复**"。

**题**：最长无重复子串 / 最小覆盖子串 / 无重复最长子串 / 和为 K 的子数组（计数+前缀）。
> **★ 挂钩**：滑动窗口就是你处理 **prompt / context 截断** 的思维——"在一段连续文本里找满足条件的最长子片段"。面试时点一句"这和我做上下文截断/滑窗检索的思路一致"。

## Part 4 二分查找（★你有真实钩子：版本号比较）

**适用**：**有序** + 能判断"mid 左边满足/右边满足"。
```python
# 找第一个 >= target 的位置（左闭右开）
lo, hi = 0, len(nums)          # 找左边界用左闭右开
while lo < hi:
    mid = (lo + hi) // 2
    if nums[mid] < target: lo = mid + 1
    else: hi = mid
return lo
```
**背这个"左闭右开求左边界"模板**，几乎所有二分变体都由它改造：
- 找最后一个 <= target：把 `<` 改 `<=`、闭区间。
- 二分答案（**可背**）：如果"答案越大越容易/越难"有单调性，就二分这个答案。

**★ 版本号比较（你的真实钩子，必练）**：
你天天处理 `max 1.13.1pre9`、`v1.12.0-pre.72` 这类版本号（`pre` = 预发布，比正式版小）。**版本比较不是字符串直接比**（`"1.13" < "1.9"` 字符串比较会错）。正确做法：拆成数字段+预发布标记逐段比。
```python
def cmp_ver(a: str, b: str) -> int:
    def parse(v):
        v = v.split('-')[0]                       # 去掉 -pre.72
        core, _, pre = v.partition('pre')         # 分离 预发布标记
        nums = [int(x) for x in core.split('.')]
        return nums, bool(pre)                    # 有 pre → 是预发布 → 小于正式版
    na, pa = parse(a); nb, pb = parse(b)
    for x, y in zip(na, nb):
        if x != y: return 1 if x > y else -1
    if pa != pb: return -1 if pa else 1            # 正式版 > 预发布
    return 0
```
> **面试话术**："我的项目里版本号带 pre（预发布）标记，我处理过 `1.13.1pre9` 和 `1.12.0-pre.72` 的排序，**不能直接字符串比较**（`1.13` 会小于 `1.9`），要拆数字段并把预发布版排在正式版之前。"**这个钩子把枯燥的版本比较讲成"我在项目里踩过版本号排序的坑"，非常真实。**

**题**：搜索插入位置 / 二分求平方根 / 旋转数组找最小值 / 第一个错误版本 / 峰值。

## Part 6 树：遍历 / 构建 / 路径（★呼应 CRG 建图）

**遍历模板（背熟）**：
```python
# 前序（根左右）
def preorder(n): 
    if not n: return
    visit(n); preorder(n.left); preorder(n.right)
# 中序（左根右）★ BST 场景
def inorder(n):
    if not n: return
    inorder(n.left); visit(n); inorder(n.right)
# 层序（★最常考，用队列）
from collections import deque
def levelorder(root):
    if not root: return []
    q, res = deque([root]), []
    while q:
        node = q.popleft(); res.append(node.val)
        if node.left:  q.append(node.left)
        if node.right: q.append(node.right)
    return res
```
- **前/中/后序的区别**在"visit 放哪一行"（根前/根后）。**前序+中序 可唯一还原二叉树**（高频构建题）。
- **层序（广度优先 BFS）**用 `deque`；**深度优先（DFS）**用递归或显式栈。
- **最大值/最小值**：`max(left_sub, right_sub)` + 本节点；**路径和**：DFS 传累积和，回溯时减去（**注意回溯还原**）。
- **层序"按层锯齿"**（每层方向交替）也是常考变体。

> **★ 挂钩**：树遍历是你 **code-review-graph 用 Tree-sitter 把代码解析成结构树**再遍历的基础。"我用 Tree-sitter 把函数/调用/定义建成树，然后 DFS 找调用链"——**这就是树上遍历的工程版**。面试时点明"我的 CRG 就是把代码建成树再遍历检索"。

**题**：最大深度 / 对称二叉树 / 层序遍历 / 从上到下打印 / 前中后序 / 最近公共祖先 LCA（★）/ BST 搜索 / 路径和。

## Part 7 图：BFS / DFS / 拓扑排序（★CRG 核心）

**适用**：连通性、最短路（无权）、依赖/环检测。
```python
from collections import deque
# BFS：层序扩展，无权最短路
def bfs(g, start):
    q, seen = deque([start]), {start}
    while q:
        u = q.popleft()
        for v in g[u]:
            if v not in seen: seen.add(v); q.append(v)

# ★ 拓扑排序（Kahn 入度法）——判有向无环图 + 依赖顺序
from collections import deque
def topo(n, edges):
    g, indeg = [[] for _ in range(n)], [0]*n
    for u, v in edges: g[u].append(v); indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    res = []
    while q:
        u = q.popleft(); res.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0: q.append(v)
    return res if len(res) == n else []   # 不足 n → 有环
```
- **BFS vs DFS**：BFS 按层（求无权最短路、层序）；DFS 深入（找路径、判环、拓扑前的后序）。**"求最短步数/层数"→ BFS**；"找所有路径/判是否有环"→ DFS。
- **拓扑排序**：入度为 0 的先出队；**输出数 < 节点数 = 有环**（依赖成环/死锁检测——**呼应你的死锁/FSM 状态机**）。
- **网格图**（岛屿数量）：把网格当图，DFS 泛洪四方向。

> **★ 挂钩**：
> - **岛屿数量/网格 DFS** = 你用 Tree-sitter/图结构在代码库里检索"调用图连通性"的直接类比。
> - **拓扑排序** = 你"把 config/模块按依赖顺序加载"、FSM 状态迁移"从初态按序推进"同构。**讲"我用拓扑排序思想理清模块依赖/状态迁移顺序"很自然。**
> - **LCA/依赖冲突** = 合并冲突（你解过 feature 分支 merge 冲突）也可以类比"找两个分支的共同祖先"。

**题**：岛屿数量 / 腐烂的橘子（层序 BFS）/ 课程表（拓扑）/ 克隆图 / 单词接龙（BFS 建图）/ 拓扑排序 / 网格最短路。

## Part 8 动态规划（只背最常考的骨架）

**DP 三步（能说出来就够面试用）**：
1. **定义状态** `dp[i]` / `dp[i][j]` 表示什么。
2. **写转移方程**（当前状态怎么由之前推来）。
3. **确定初始值与遍历顺序**。
> **口诀：状态定义 → 转移方程 → 初始/边界。** 面试时先把这三步说出来，再写代码。

**最常考 4 类**：
```python
# ① 线性 DP：爬楼梯（dp[i]=dp[i-1]+dp[i-2]）
# ② 完全背包：dp[j]=max(dp[j], dp[j-w]+v)，一维从大到小防重复
# ③ 区间/双序列：dp[i][j] 由 dp[i-1][j], dp[i][j-1] 推（如编辑距离）
# ④ 选或不选：0/1 背包 dp[j]=max(dp[j], dp[j-w]+v)，一维从小到大保证只选一次
```
- **斐波那契（爬楼梯）** 必会，能 O(1) 空间。
- **背包**：01 背包（每件一次，**一维从小到大**）、完全背包（每件无限，**一维从大到小**）。**这两个方向记反是高频错。**
- **编辑距离**（字符串编辑）是 Agent/RAG 高频延伸（模糊检索/similarity），**值得练熟**。

**题**：爬楼梯 / 买卖股票 / 最大子数组和 / 零钱兑换（完全背包）/ 01背包 / 编辑距离 / 最长公共子序列 LCS / 分割等和子数组。

## Part 9 贪心与排序（够用即可）

- **贪心**：每步选当前最优（**要能证明局部最优→全局最优才敢用**，如"区间调度选最早结束"）。**不一定都对**（如硬币找零贪心可能错）。
- **排序**：`sort` key 技巧、自定义比较（**注意返回负数表示"排在前面"**）。
```python
nums.sort(key=lambda x: -x)                      # 降序
intervals.sort(key=lambda x: x[1])               # 按右端点排（区间调度）
intervals.sort(key=lambda x: (x[0], x[1]))       # 多关键字
```

## Part 10 手写题专项：LRU 缓存（★必考）

> **LRU 是笔试/面试出现率最高的"手写设计题"之一**，且能顺势引出 KV Cache / Prompt Caching（见大模型底层册）。**必须能默写。**

**原理**：**哈希表 + 双向链表**。哈希表 O(1) 定位节点，双向链表维护最近使用顺序（头部最新、尾部最久未用，容量满淘汰尾部）。
```python
class Node:
    def __init__(self, key=0, val=0):
        self.key, self.val = key, val
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}                       # key -> Node
        self.head = Node()                    # 哨兵：最新
        self.tail = Node()                    # 哨兵：最久未用
        self.head.next, self.tail.prev = self.tail, self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_front(self, node):
        node.next, node.prev = self.head.next, self.head
        self.head.next.prev = node.prev = node

    def get(self, key):
        if key not in self.cache: return -1
        node = self.cache[key]
        self._remove(node); self._add_front(node)   # 访问→提到最前
        return node.val

    def put(self, key, val):
        if key in self.cache:
            self._remove(self.cache[key])
        if len(self.cache) >= self.cap:              # 淘汰尾部（最久未用）
            lru = self.tail.prev
            self._remove(lru); del self.cache[lru.key]
        node = Node(key, val)
        self.cache[key] = node; self._add_front(node)
```
**面试话术**：
> "LRU 用**哈希表 + 双向链表**：哈希表 O(1) 定位，双向链表维护使用顺序，get/put 都把节点提到头部，满了淘汰尾部，整体 O(1)。**我理解它和推理里的 KV Cache 淘汰、以及 Prompt Caching 的前缀缓存是同构的问题**——都是'有限的快速存储 + 按使用热度/时间淘汰底层'。"
