# 大模型底层长期学习路线图

> 用途：面试**之后**，系统性地从"入门过一点"转向大模型底层的**多月学习路径**（不是面试突击）。
> 定位：你现在 DL 基础尚浅，但有 **C++ / 控制系统 / 测试**的工程底子。
> 更新时间：2026-08-17。配套面试清单见《Coding Agent岗位面试刷题准备清单-v3.md》。

---

## 0. 先定方向：你最该走「推理系统」这条底层支线

大模型底层其实分三条差别很大的支线，别一上来什么都学：

| 支线 | 干什么 | 吃什么能力 | 和你的匹配度 |
|---|---|---|---|
| **A. 算法/研究**（训练、对齐、新架构） | 设计模型、训练方法 | **重数学**（概率/优化/统计） | ⚠️ 最不吃你现有优势 |
| **B. 推理系统/Serving**（vLLM 那类） | 让模型**跑得快、省显存、稳定** | **C++ / 系统 / 并发 / 性能调优** | ✅ **最贴你的 C++ + 控制系统 + 测试背景** |
| C. 训练基建（分布式训练框架） | 大规模训练的工程 | 分布式 / 通信 / 系统 | 🔸 次选，B 打好后可延伸 |

**强烈建议主攻 B（推理系统）**，理由：
- 你的 **C++ 控制系统经验**（实时性、性能、并发、和硬件打交道）几乎可以**直接平移**到推理引擎/kernel 优化。
- 你的**测试背景**在推理系统里是稀缺优势（性能基准、正确性验证、稳定性压测正是这行的日常）。
- 它离数学最远、离工程最近——对"入门过一点"的你最友好，能最快做出成果。
- 它和 Coding Agent 直接相关：Agent 再强，也要有人把底下的模型**服务化、跑稳、压成本**。

> 下面的路线图里，**Transformer 和训练对齐是"必须懂的地基"（Phase 1-2 求理解即可）**，而 **Phase 3（推理系统）才是你要深挖、要做出项目、要写进简历的主战场**。

---

## 学习总原则（比学什么更重要）

1. **项目驱动，拒绝只看不写**：每个阶段都要有一个**能跑、能写进简历/GitHub**的产出物（下面每阶段都标了）。你之前从零训 nanoGPT、复刻 Letta 就是对的路子，继续这么干。
2. **费曼检验**：每学一个概念，逼自己"能不能用大白话给别人讲清楚 + 画个图"。讲不清 = 没懂。你本来就有写中文教学文档的习惯，保持。
3. **先直觉后推导**：先看图解建立直觉，再回头补公式。别一上来啃论文公式，会劝退。
4. **复现 > 阅读**：读懂一篇不如亲手复现一小块。推理系统尤其要动手 profile、改代码、看指标。

## Phase 0 · 地基：数学直觉 + 深度学习基础（约 3–4 周）

**目标**：补上"入门过一点"缺的系统性，能看懂后面的论文和代码。

**核心内容**：线代（矩阵乘法、维度变换的直觉）、概率与求导直觉、神经网络基础（前向/反向传播、损失、梯度下降）、PyTorch 基本操作。

**📚 资源**
- 🟢 [3Blue1Brown《线性代数的本质》/《神经网络》系列](https://www.3blue1brown.com/)（B 站有中字，建立几何直觉最佳）
- 🟢 [李沐《动手学深度学习》(PyTorch 版)](https://zh.d2l.ai/)（**本路线图主力教材**，带代码，边看边跑）
- 🟢 Karpathy《Neural Networks: Zero to Hero》（YouTube，搜索标题；从零手写反向传播，神课）

**产出物**：跟着 d2l 手写一个 MLP + CNN 跑通 MNIST，写一篇中文笔记讲清"反向传播到底在干嘛"。

---

## Phase 1 · 吃透 Transformer（约 3–4 周）

**目标**：能从零讲清并实现一个 Transformer；理解注意力的所有主流变体。

**核心内容**：自注意力、多头注意力、位置编码（sin/cos → **RoPE** → ALiBi）、LayerNorm/RMSNorm、Encoder-Decoder vs Decoder-only、分词器（BPE）。**注意力变体**：MHA → MQA → GQA（为什么省 KV cache）、**FlashAttention**（省显存搬运的思想）。

**📚 资源**
- 🟢 [图解 Transformer（中文·宝玉译）](https://baoyu.io/translations/llm/illustrated-transformer)｜🔴 [英文原文](https://jalammar.github.io/illustrated-transformer/)
- 🟢 [Karpathy nanoGPT](https://github.com/karpathy/nanoGPT)（**你已跑过一部分，这次逐行读懂 + 改**）
- 🟡 [苏剑林·科学空间（kexue.fm）](https://kexue.fm/)（搜"RoPE""Transformer 位置编码"，中文讲位置编码最透）
- 🔴 [Attention Is All You Need（原论文）](https://arxiv.org/abs/1706.03762)

**产出物**：在 nanoGPT 基础上**自己动手把 MHA 改成 GQA**，对比显存/速度，写成一个小实验 + 中文讲解（这直接补齐你简历的 L3"从 0 动手改模型"证据）。

---

## Phase 2 · 训练与对齐（约 3–4 周，求"理解"不求"精通"）

**目标**：讲清一个模型从预训练到能对话，中间经历了什么。

**核心内容**：预训练目标；**SFT**；参数高效微调（**LoRA**）；对齐（**RLHF** 三阶段 → **DPO** 为什么更简单）；Scaling Law 与涌现；解码策略（贪心/Beam/采样、温度/TopP/TopK）。

**📚 资源**
- 🟢 [知乎《人机对齐：从 RLHF 到 DPO》](https://zhuanlan.zhihu.com/p/10059528011)｜🟡 [HuggingFace 中文《从 RLHF 到 DPO》](https://hugging-face.cn/blog/ariG23498/rlhf-to-dpo)
- 🟡 [HuggingFace LLM/NLP Course](https://huggingface.co/learn)（系统、带实操）

**产出物**：用 LoRA 微调一个小模型（如 Qwen-0.5B）做个小任务，写清"微调改了什么、没改什么"。**这一阶段够用即可，别陷进去**——你的主战场在 Phase 3。

---

## Phase 3 · 推理系统 / Serving（★你的主战场，约 6–8 周，深挖）

**目标**：这是你要做深、做出项目、写进简历、面试能当主场讲的部分。

**核心内容**：
- 推理两阶段 **prefill / decode** 的性能特征；吞吐 vs 延迟。
- **KV Cache** 原理与显存占用；**PagedAttention**（借鉴 OS 分页管理 KV Cache）——**这块你的操作系统/系统知识直接用得上**。
- **连续批处理（continuous batching）**、投机解码（speculative decoding）。
- **量化**（INT8/INT4、AWQ/GPTQ）；**MoE** 推理。
- 读 **vLLM 源码**，亲手 benchmark、profile、调参（**你的测试功底在这里是优势**）。

**📚 资源**
- 🟢 [阿里云《vLLM PagedAttention 原理详解》](https://developer.aliyun.com/article/1664805)｜🟡 [July 博客·一文通透 vLLM 与 PagedAttention](https://blog.csdn.net/v_JULY_v/article/details/144218958)
- 🟡 [KV Cache 深度解析（知乎）](https://zhuanlan.zhihu.com/p/2016843212178882587)
- 🔴 [vLLM 官方仓库 + 文档](https://github.com/vllm-project/vllm)（读源码、跑 benchmark）
- 🔴 [PagedAttention / vLLM 论文](https://arxiv.org/abs/2309.06180)

**产出物（含金量最高）**：
- 用 vLLM 部署一个模型，做一份**推理性能基准报告**（不同 batch/量化/上下文长度下的吞吐-延迟-显存对比）——**这份报告 = 你 C++/测试背景 × 大模型底层的完美结合，直接能写进简历当核心项目**。
- 进阶：给 vLLM 提一个小 PR，或用 C++/CUDA 手写一个简单算子。

## 里程碑自检（学到位没有）

- **Phase 1 过关**：能白板画出 Transformer 数据流，讲清 MHA→GQA 为什么省显存。
- **Phase 2 过关**：能讲清 RLHF 和 DPO 的区别、LoRA 改了什么。
- **Phase 3 过关（关键）**：能讲清 prefill/decode 差异、KV Cache 为什么吃显存、PagedAttention 怎么解决、能拿出一份自己的推理基准报告。
- **终极检验**：回头去做那篇[月之暗面「大模型 LLM 一面」面经](https://www.nowcoder.com/discuss/875874293186379776)的题（prefill/decode、OOM 排查、MHA 计算量、PagedAttention、FlashAttention），能答上来 = 你真的转型成功了。

## 时间预期与心态

- **总周期**：认真投入约 **4–6 个月**（每周 10–15 小时）能到"能面底层岗"的程度。**这不是几天能速成的**，别用面试的紧迫感来学它，会崩。
- **节奏**：先靠 A 拿下这次 offer 上岸 → 在岗位/业余按这个路线图走 → 半年后你就有资本谈"往推理系统方向转"。
- **你的独特优势**：C++ 控制系统 + 测试，在**推理系统**这条支线上是真优势，别去和数学系卷训练算法。**扬长，别补短到怀疑人生。**

> 一句话：**面试用 A 上岸，底层用这份路线图长期打——推理系统(Phase 3)是你的最优解，其余是地基。**
